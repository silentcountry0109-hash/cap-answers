# 國中自然 歷屆會考考題｜答案與詳解（典陸教育集團）

《國中自然 歷屆會考．大考考題精選》第一～三冊題本的配套網頁。

- 網址：https://cap-pastpapers.danlu-education.com/（沿用題本 QR Code 網址）
- 舊版圖片站保留於 https://silentcountry0109-hash.github.io/cap-pastpapers/
- 發佈分支：`gh-pages`（與 `main` 同步推送）
題號、頁碼一律依**題本印刷**標示；答案與解析取自翰林 114 學年度教用合檔。

| 冊別 | 範圍 | 章 | 作答題數 |

## 重新建置

`tools/` 內腳本讀取教用／學用合檔 PDF 與三冊題本 PDF（不在 repo 中）：

```bash
pip install pymupdf pillow
python tools/parse.py        # 切分題號、答案、解析區塊
python tools/verify_vol.py   # 題本 ↔ 學用逐頁比對
python tools/book.py         # 題號對齊題本
python tools/build_site.py   # 產生網站
```
